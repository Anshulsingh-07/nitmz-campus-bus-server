# NIT Mizoram Campus Bus Tracker

Flutter app and Node/Express API for campus bus locations, schedules, caretaker
management, and driver trip updates.

## Repository layout

- `flutter_app/` — Flutter mobile app (Android release APK and Flutter Web).
- `my_server/` — Express API, PostgreSQL schema/bootstrap, and telemetry tools.
- `render.yaml` — Render Blueprint for the backend web service.
- `DEPLOYMENT.md` — setup, deployment, and release build instructions.

See [DEPLOYMENT.md](DEPLOYMENT.md) for a fresh-clone deployment walkthrough.
